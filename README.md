# 🍽️ Grilli - Modern & Responsive Restaurant Website

A sleek, fully responsive, and interactive restaurant landing page built for **Grilli**. Designed to deliver a smooth user experience with a modern culinary aesthetic, rich media, interactive reservation interface, and clean UI navigation.

---

## ✨ Features

- **Responsive Design:** Flawlessly optimized across desktop, tablet, and mobile screens.
- **Interactive Menu Showcase:** Highlighted signature dishes, categories, and special offers.
- **Table Reservation Form:** Interactive reservation form UI for guest bookings.
- **Special Events & Chef Highlights:** Dedicated sections for upcoming culinary events and chef stories.
- **Custom Aesthetic & Assets:** Styled with custom typography, rich visual layouts, and smooth transition effects.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for structure and SEO optimization.
- **CSS3:** Custom styles, animations, CSS Grid, and Flexbox for layout management.
- **JavaScript (ES6+):** Interactive elements, mobile navigation toggles, and UI interactions.
